# Specta + tauri-specta Cheat Sheet

**Pinned versions (DevPulse):**
- `specta` = 2.0.0-rc.22 (features: derive, function, uuid)
- `specta-typescript` = 0.0.9
- `tauri-specta` = 2.0.0-rc.21 (features: derive, typescript)

---

## The Golden Rule

**Every struct/enum that crosses the Tauri IPC boundary MUST derive `specta::Type`.**
If it derives `Type` and has `i64`/`u64`/`i128`/`u128` fields, configure `BigIntExportBehavior` or it PANICS at startup.

---

## BigIntExportBehavior (CRITICAL)

Default is `Fail` — panics on any i64/u64 field in a Type-derived struct.

```rust
use specta_typescript::{Typescript, BigIntExportBehavior};

// In lib.rs where builder.export() is called:
builder.export(
    Typescript::default()
        .bigint(BigIntExportBehavior::Number),  // i64 → number in TS
    "../src/lib/sys/generated/bindings.ts",
)?;
```

| Variant | TS Output | When to Use |
|---------|-----------|-------------|
| `Number` | `number` | Counts, timestamps, IDs that fit in JS Number (< 2^53) |
| `String` | `string` | Values that may exceed 2^53, need precision |
| `BigInt` | `bigint` | When frontend uses native BigInt |
| `Fail` | PANIC | Default. Forces you to decide. |

**WARNING**: This only changes the TypeScript TYPE. Your serde serializer must match. JSON serializes i64 as number by default, so `Number` is the safe choice for JSON-over-IPC.


## Derive Attributes

### Container-level (on struct/enum)

```rust
#[derive(Serialize, Type)]
#[serde(rename_all = "camelCase")]     // Field names → camelCase in TS
#[serde(tag = "type")]                 // Internally tagged enum
#[serde(tag = "t", content = "c")]     // Adjacently tagged enum
#[serde(untagged)]                     // Untagged union in TS
#[serde(transparent)]                  // Export as inner type, not wrapper
#[specta(rename = "MyTsName")]         // Override TS type name
#[specta(export = false)]              // Exclude from auto-collection
```

### Field-level

```rust
#[derive(Serialize, Type)]
pub struct Example {
    #[serde(rename = "userName")]       // Field name in TS
    pub user_name: String,

    #[serde(skip)]                      // Omit from TS export
    pub internal: bool,                 // Prefer #[specta(skip)] instead

    #[specta(skip)]                     // Omit from TS (processed at macro time)
    pub cache: HashMap<String, String>,

    #[serde(flatten)]                   // Merge fields into parent type
    pub metadata: Metadata,

    #[serde(default)]                   // Makes field optional in TS (field?: type)
    pub optional_field: String,

    #[specta(inline)]                   // Inline the type definition
    pub config: Config,

    #[specta(type = String)]            // Override the exported type
    pub custom: PathBuf,
}
```

### Precedence: `#[specta(...)]` overrides `#[serde(...)]` when both specify the same property.

## Supported Rust Types → TypeScript

| Rust | TypeScript | Notes |
|------|-----------|-------|
| `String`, `&str` | `string` | |
| `bool` | `boolean` | |
| `i8`–`i32`, `u8`–`u32` | `number` | Safe, fits in JS |
| `i64`, `u64` | Depends on BigIntExportBehavior | **Configure or panic** |
| `i128`, `u128` | Depends on BigIntExportBehavior | Same |
| `f32`, `f64` | `number` | |
| `Option<T>` | `T \| null` | |
| `Vec<T>` | `T[]` | |
| `HashMap<K, V>` | `Record<K, V>` | K must be string-like |
| `HashSet<T>` | `T[]` | |
| `(A, B, C)` | `[A, B, C]` | Tuple |
| `()` | `null` | Unit |
| `Result<T, E>` | `T` (Ok) or `E` (Err) | Depends on context |
| `uuid::Uuid` | `string` | Needs `uuid` feature |
| `chrono::DateTime` | `string` | Needs `chrono` feature |
| `serde_json::Value` | `unknown` | |
| `Box<T>`, `Arc<T>`, `Rc<T>` | `T` | Transparent wrappers |

## tauri-specta v2 Wiring Pattern

### 1. Annotate Commands

```rust
#[tauri::command]
#[specta::specta]                          // BOTH attributes required
pub async fn my_command(
    state: State<'_, MyState>,
    arg: String,
) -> Result<MyResponse, String> {          // Return types MUST derive Type
    // ...
}
```

### 2. Register in lib.rs

```rust
use tauri_specta::{collect_commands, collect_events, Builder};

let builder = Builder::<tauri::Wry>::new()
    .commands(collect_commands![
        commands::chat::send_message,
        commands::devpulse::fetch_dashboard,
    ])
    .events(collect_events![
        MyEvent,
    ]);

// Dev: export bindings
#[cfg(debug_assertions)]
builder.export(
    Typescript::default()
        .bigint(BigIntExportBehavior::Number),
    "../src/lib/sys/generated/bindings.ts",
)?;

// Wire into Tauri
tauri::Builder::default()
    .invoke_handler(builder.invoke_handler())
    .setup(move |app| {
        builder.mount_events(app);
        Ok(())
    })
```

### 3. Frontend Usage (generated bindings.ts)

```typescript
import { commands } from "$lib/sys/generated/bindings";

// Fully typed — args and return type inferred
const result = await commands.fetchDashboard();
```

## Typed Events (tauri-specta v2)

```rust
// Define event type
#[derive(Debug, Clone, Serialize, specta::Type, tauri_specta::Event)]
pub struct BootProgress {
    pub step: String,
    pub status: String,
    pub latency_ms: u64,     // Safe with BigInt::Number
}

// Emit from Rust
BootProgress { step: "LibSQL".into(), status: "ready".into(), latency_ms: 42 }
    .emit(&app_handle)?;

// Listen in frontend (from generated bindings)
import { events } from "$lib/sys/generated/bindings";
events.bootProgress.listen((data) => {
    console.log(data.payload.step);  // Fully typed
});
```

## Common Mistakes

### 1. Missing `#[specta::specta]` on command
```
Error: function not found in collect_commands
```
Fix: Add `#[specta::specta]` below `#[tauri::command]`.

### 2. BigIntForbidden panic
```
thread 'main' panicked at 'BigIntForbidden(path -> field -> u64)'
```
Fix: Configure `.bigint(BigIntExportBehavior::Number)` on the Typescript exporter. Do NOT downcast types.

### 3. Type not deriving specta::Type
```
the trait `Type` is not implemented for `MyStruct`
```
Fix: Add `specta::Type` to the derive list. Ensure all nested types also derive Type.

### 4. Version mismatch between specta crates
Pin exact RC versions: `specta = "=2.0.0-rc.22"`, `tauri-specta = "=2.0.0-rc.21"`. Mismatched RCs break.

### 5. Serde rename not reflected in TS
Specta reads `#[serde(rename_all = "camelCase")]` automatically. If it's not working, check that `specta-serde` feature is enabled.

## DevPulse-Specific Notes

- **All IPC structs** in `commands/` derive `Serialize + Type`
- **BigInt policy**: `Number` — all our i64 values are counts/timestamps within JS Number range
- **Bindings output**: `interfaces/desktop/src/lib/sys/generated/bindings.ts`
- **Export runs**: Debug builds only (`#[cfg(debug_assertions)]`)
- **Engine types** that cross IPC (SystemHealth, InitEvent, etc.) also derive Type via `specta::Type` import in engine crate
- **13 files** import specta::Type across engine + tauri — any new IPC struct needs it
