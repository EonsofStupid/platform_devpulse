# Select Primitive — Accessibility Contract

> Dropdown selection for single or multiple values.
> Based on [WAI-ARIA Listbox Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/listbox/).

---

## Key Differences from Popover

| Aspect | Popover | Select |
|--------|---------|--------|
| Role | None (disclosure) | `listbox` / `option` |
| Purpose | General floating content | Selection from options |
| Close behavior | Click outside/escape | Also on selection (single mode) |
| Typeahead | No | Yes |
| Selection state | None | `selected`, `highlighted` |

---

## ARIA Behavior

| Attribute | Element | Value | Source |
|-----------|---------|-------|--------|
| `role` | Content | `"listbox"` | Bits UI |
| `role` | Item | `"option"` | Bits UI |
| `aria-haspopup` | Trigger | `"listbox"` | Bits UI |
| `aria-expanded` | Trigger | `"true"` / `"false"` | Bits UI |
| `aria-activedescendant` | Trigger | Highlighted item ID | Bits UI |
| `aria-selected` | Item | `"true"` / `"false"` | Bits UI |
| `aria-multiselectable` | Content | `"true"` (when multiple) | Bits UI |
| `aria-disabled` | Item | `"true"` (when disabled) | Bits UI |

## Keyboard Interaction

### When Closed (Trigger Focused)

| Key | Action |
|-----|--------|
| `Enter` / `Space` | Opens select |
| `ArrowDown` | Opens, highlights first item |
| `ArrowUp` | Opens, highlights last item |
| Type character | Opens, highlights matching item (typeahead) |

### When Open

| Key | Action |
|-----|--------|
| `Escape` | Closes select |
| `Tab` | Closes select, moves focus |
| `ArrowDown` | Highlights next item |
| `ArrowUp` | Highlights previous item |
| `Home` | Highlights first item |
| `End` | Highlights last item |
| `PageDown` | Highlights 10 items forward |
| `PageUp` | Highlights 10 items backward |
| `Enter` / `Space` | Selects highlighted item |
| Type character | Highlights matching item (typeahead) |

---

## Focus Management

1. **On open (click/Enter/Space):** Focus moves to content, highlight on selected or first item
2. **While open:** Arrow keys move highlight (not DOM focus), scroll follows
3. **On select (single):** Select closes, focus returns to trigger
4. **On select (multi):** Select stays open, highlight stays on item
5. **On escape:** Select closes, focus returns to trigger

## Data Attributes

| Attribute | Values | Purpose |
|-----------|--------|---------|
| `data-kind` | `"select"` | CSS primitive targeting |
| `data-slot` | See SelectSlots | CSS slot targeting |
| `data-state` | `"open"` / `"closed"` | Root/Content state |
| `data-selected` | Present when selected | Item selection indicator |
| `data-highlighted` | Present when highlighted | Item highlight indicator |
| `data-disabled` | Present when disabled | Item disabled indicator |
| `data-side` | Position side | Content positioning |
| `data-align` | Position alignment | Content positioning |
| `data-id` | User-defined | Testing/tooling |
