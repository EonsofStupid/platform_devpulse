## USER TIERS

### Tier 0: Non-Coder ("Vibe Coder" — DevPulse primary target)
Prompt: Lowest. Verification: Accepts first output. Error recovery: Restarts or gives up.
Economic exposure: HIGHEST — pays learning tax through failed iterations.
MAESTRO: Max TEACHER, max SCRIBE, max GUARDIAN.

### Tier 1: Beginner Coder
Prompt: Low, knows some terms but uses them wrong. Verification: "Looks right" visual.
Error recovery: Same prompt, different words. Absorbs terminology when exposed naturally.
MAESTRO: High TEACHER, high SCRIBE. GUARDIAN surfaces completion %.

### Tier 2: Competent Dev
Prompt: Medium, can specify requirements. Verification: Runs tests, reviews diffs.
Error recovery: Reads error messages, adjusts. Actively seeks patterns.
MAESTRO: Low TEACHER, medium SCRIBE. Medium GUARDIAN.

### Tier 3: AI Power User
Prompt: High, COSTAR-level. Verification: Multi-layer. Session discipline: strategic.
Teaches the AI (self-improving CLAUDE.md loop). Knows internal limitations.
MAESTRO: TEACHER off. GUARDIAN active (even experts miss CC-007 renames).
