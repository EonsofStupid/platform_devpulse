# SvelteKit Project Structure Alignment Plan

## Goal
Align `interfaces/desktop/` to standard SvelteKit best practices so that:
- `interfaces/desktop/` = project root (all configs)
- `interfaces/desktop/src/` = UI source ONLY (Svelte 5 + SvelteKit)
- No deprecation warnings
- No cruft

---

## Target Structure

```
interfaces/desktop/                <- PROJECT ROOT
├── package.json                   <- merged, all deps
├── pnpm-lock.yaml
├── svelte.config.js               <- NO files config (standard paths)
├── vite.config.ts
├── tsconfig.json                  <- extends .svelte-kit/tsconfig.json
├── tsconfig.node.json
├── tailwind.config.ts             <- content paths prefixed with src/
├── vitest.config.ts               <- paths prefixed with src/
├── node_modules/
├── .svelte-kit/                   <- generated by SvelteKit
├── src/                           <- UI SOURCE ONLY
│   ├── app.html                   <- SvelteKit HTML template
│   ├── app.css                    <- global styles
│   ├── routes/                    <- SvelteKit file-based routing
│   │   ├── +layout.svelte
│   │   ├── +page.svelte
│   │   └── (app)/                 <- route groups
│   └── lib/                       <- $lib alias
│       ├── design/                <- ColdLight design system
│       ├── domains/               <- domain components
│       ├── layouts/               <- layout components
│       ├── sys/                   <- system utilities
│       └── test/                  <- test utilities
├── src-tauri/                     <- Tauri Rust backend (separate)
└── scripts/                       <- build/dev scripts
```
