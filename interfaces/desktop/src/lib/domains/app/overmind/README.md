# OverMind (The Ephemeral Sandbox)

> **Philosophy**: "Where thinking happens."
> **Status**: Ephemeral (Low-Weight Vectors).
> **Rule**: Nothing leaves here unless explicitly **Graduated** or **Saved**.

## The 4 Pillars of OverMind
1.  **Learning**: Research, Analytics, Education (The Classroom).
2.  **Theorycrafting**: "What if?" scenarios, Idea Bouncing, Echo Chamber.
3.  **Prototyping**: Code staging, UI Design ideas, Safe testing (Sandboxed).
4.  **CLI/Terminal**: A lowered-barrier, UI-driven way to learn Command Line.

## Governance & Policies
*   **Ephemerality**: 30-Day Auto-Eviction (unless saved).
*   **Safety**: Sandboxed execution. No impact on Core Project Memories.
*   **Graduation**: Explicit user action required to move to `libSQL` (Project).

## The Persona Cards (Standard Loadout)
We provide these Sub-Agents to help the user theorycraft:
1.  **The Researcher**: "Find everything about X."
2.  **The Architect**: "Structure this idea."
3.  **The Scientist**: "Test this hypothesis."
4.  **The Engineer**: "Build this prototype."
5.  **The Carmack**: "Optimize this code." (The Coder).

## Structure (Strict Hyper-Modular)
*   `services/`: Ephemeral state logic (stores low-weight vectors).
*   `components/`: The UI Cards (ExplorationCard, PersonaCard).
*   `stores/`: Svelte 5 Runes for local session state.
*   `pages/`: The Dashboard layouts (Learning, Prototyping).
*   `utils/`: Sandbox-specific helpers.
