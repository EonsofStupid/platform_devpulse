# Dialog Primitive — Accessibility Contract

> **ColdLight is the SINGLE SOURCE OF TRUTH.**
> ALL ARIA attributes, roles, and IDs are owned by ColdLight.
> bits-ui provides ONLY behavior (focus trap, escape, click outside, portal, scroll lock).

---

## ARIA OWNERSHIP

### ColdLight Sets EXPLICITLY

| Attribute | Element | Value | Set By |
|-----------|---------|-------|--------|
| `role` | Content | `"dialog"` | **ColdLight** |
| `aria-modal` | Content | `"true"` | **ColdLight** |
| `aria-labelledby` | Content | Title ID | **ColdLight** |
| `aria-describedby` | Content | Description ID | **ColdLight** |
| `tabindex` | Content | `-1` | **ColdLight** |
| `id` | Content | Generated | **ColdLight** |
| `id` | Title | Generated | **ColdLight** |
| `id` | Description | Generated | **ColdLight** |
| `aria-haspopup` | Trigger | `"dialog"` | **ColdLight** |
| `aria-expanded` | Trigger | `"true"` / `"false"` | **ColdLight** |
| `aria-controls` | Trigger | Content ID | **ColdLight** |

### bits-ui Provides ONLY Behavior

| Behavior | Description |
|----------|-------------|
| Focus trapping | Tab key cycles within Content |
| Escape key | Fires `onEscapeKeydown` callback |
| Click outside | Fires `onInteractOutside` callback |
| Portal | Renders Content to `document.body` |
| Scroll lock | Prevents body scroll when open |
| Presence | Manages mount/unmount animations |

## ID LINKING PATTERN

```
Root.svelte
  ├── const contentId = useId()
  ├── const titleId = useId()
  ├── const descriptionId = useId()
  └── setContext("dialog-ids", { contentId, titleId, descriptionId })

Content.svelte
  ├── const { contentId, titleId, descriptionId } = getContext("dialog-ids")
  └── <div
        id={contentId}
        role="dialog"
        aria-modal="true"
        aria-labelledby={titleId}
        aria-describedby={descriptionId}
        tabindex={-1}
      >

Title.svelte
  ├── const { titleId } = getContext("dialog-ids")
  └── <h2 id={titleId}>

Description.svelte
  ├── const { descriptionId } = getContext("dialog-ids")
  └── <p id={descriptionId}>

Trigger.svelte
  ├── const { contentId } = getContext("dialog-ids")
  └── <button
        aria-haspopup="dialog"
        aria-expanded={open}
        aria-controls={contentId}
      >
```

## KEYBOARD INTERACTION

| Key | Element | Action |
|-----|---------|--------|
| `Enter` | Trigger | Opens dialog |
| `Space` | Trigger | Opens dialog |
| `Escape` | Content | Closes dialog (if `closeOnEscape=true`) |
| `Tab` | Content | Cycles forward through focusable elements (trapped) |
| `Shift+Tab` | Content | Cycles backward through focusable elements (trapped) |

---

## FOCUS MANAGEMENT

### On Open
1. Focus moves to first focusable element inside Content
2. Focus is trapped within Content (Tab cycles, cannot escape)
3. Background scroll is locked (`preventScroll=true`)
4. Background content is inert (not focusable, not announced)

### On Close
1. Focus returns to Trigger element that opened the dialog
2. Scroll lock released
3. Background content restored

| Attribute | Values | Set By |
|-----------|--------|--------|
| `data-kind` | `"dialog"` | **ColdLight** |
| `data-slot` | `"root"` `"trigger"` `"portal"` `"overlay"` `"content"` `"title"` `"description"` `"close"` | **ColdLight** |
| `data-state` | `"open"` / `"closed"` | **ColdLight** |
| `data-id` | User-defined | **ColdLight** (passthrough) |

```css
  /* styles */

/* Dialog content - state-based animations */

  animation: dialog-in 200ms ease-out;
}

[data-kind="dialog"][data-slot="content"][data-state="closed"] {
  animation: dialog-out 150ms ease-in;
}
```

## SCREEN READER BEHAVIOR

1. **On open**: Announces dialog role and title (`aria-labelledby`)
2. **Description**: Announces description if present (`aria-describedby`)
3. **Background**: Hidden from screen readers via `aria-hidden` on body content
4. **Modal context**: `aria-modal="true"` indicates modal context

## TEST REQUIREMENTS

### ARIA Ownership Tests (MANDATORY)

```typescript
describe("ARIA ownership", () => {
  it("ColdLight sets role=dialog", async () => {
    render(DialogTest, { open: true });
    const content = document.querySelector('[data-slot="content"]');
    await expect.element(content).toHaveAttribute("role", "dialog");
  });

  it("ColdLight sets aria-modal=true", async () => {
    render(DialogTest, { open: true });
    const content = document.querySelector('[data-slot="content"]');
    await expect.element(content).toHaveAttribute("aria-modal", "true");
  });

  it("ColdLight links aria-labelledby to Title ID", async () => {
    render(DialogTest, { open: true });
    const content = document.querySelector('[data-slot="content"]');
    const title = document.querySelector('[data-slot="title"]');
    const titleId = title?.getAttribute("id");
    await expect.element(content).toHaveAttribute("aria-labelledby", titleId);
  });

  it("ColdLight links aria-describedby to Description ID", async () => {
    render(DialogTest, { open: true });
    const content = document.querySelector('[data-slot="content"]');
    const description = document.querySelector('[data-slot="description"]');
    const descriptionId = description?.getAttribute("id");
    await expect.element(content).toHaveAttribute("aria-describedby", descriptionId);
  });

  it("ColdLight sets aria-haspopup=dialog on Trigger", async () => {
    const screen = render(DialogTest);
    const trigger = screen.getByRole("button");
    await expect.element(trigger).toHaveAttribute("aria-haspopup", "dialog");
  });

  it("ColdLight sets aria-expanded on Trigger", async () => {
    const screen = render(DialogTest, { open: false });
    const trigger = screen.getByRole("button");
    await expect.element(trigger).toHaveAttribute("aria-expanded", "false");
  });

  it("ColdLight sets aria-controls on Trigger linking to Content ID", async () => {
    render(DialogTest, { open: true });
    const trigger = document.querySelector('[data-slot="trigger"]');
    const content = document.querySelector('[data-slot="content"]');
    const contentId = content?.getAttribute("id");
    await expect.element(trigger).toHaveAttribute("aria-controls", contentId);
  });

  it("IDs are generated by ColdLight (not bits-ui)", async () => {
    render(DialogTest, { open: true });
    const content = document.querySelector('[data-slot="content"]');
    const title = document.querySelector('[data-slot="title"]');
    const description = document.querySelector('[data-slot="description"]');

    // Verify IDs exist
    expect(content?.getAttribute("id")).toBeTruthy();
    expect(title?.getAttribute("id")).toBeTruthy();
    expect(description?.getAttribute("id")).toBeTruthy();

    // Verify ID linking
    expect(content?.getAttribute("aria-labelledby")).toBe(title?.getAttribute("id"));
    expect(content?.getAttribute("aria-describedby")).toBe(description?.getAttribute("id"));
  });
});
```
