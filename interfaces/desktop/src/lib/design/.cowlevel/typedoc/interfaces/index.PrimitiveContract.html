    Interface PrimitiveContract<TKind, TSlot, TState, TCollectionKey>

    The shape of a primitive contract.

    Generic parameters: TKind - Literal kind identifier ("dialog", "button", "tabs") TSlot - Union of slot names for this primitive TState - Union of state tokens for this primitive TCollectionKey - Union of collection keys ("aria" | "keyboard" etc)

    ariaStateProvider declares WHO provides ARIA+state builders. MeltUI-backed primitives: "meltui" ColdLight custom ARIA: "coldlight"
