# ColdLight Design System — Master Plan

> **@devpulse/coldlight** v0.3.0 (Updated 2026-03-16)
>
> ColdLight is a **visual compiler** — Style Dictionary 5 is the engine that drives CSS generation, TypeScript type generation, and token manifest generation. Everything downstream (components, blocks, recipes, presets, VPB controls) consumes what SD5 produces.
>
> **ColdLight is the sole authority.** The human owner directs ColdLight. ColdLight directs all CSS, all components, all generation. No library, no tool, no AI agent overrides the owner's decisions. Configuration is the owner's instrument of control — `coldlight.config.ts` declares what exists, what gets generated, and what gets enforced. Code serves the config. Config serves the owner.
>
> Visual identity: liquid metal, glass depth, SVG neumorphism, particle effects, OKLCH color system, dark-first.
> Named for Tesla's cold light gas tubes (1890s).

- shadcn/svelte, Bits UI, DaisyUI, or any competing component system
- CSS-in-JS solutions
- Legacy Svelte stores
- Inline style objects with raw color values
- Hand-written CSS for visual properties — all CSS generated by or authored within ColdLight
- Inventing CSS variable names without checking SD5 output

## Token Pipeline (SD5)

### Source
DTCG token JSON under `scripts/build/styledictionary/tokens/src/`:
- Top-level `*.json` plus `primitives/**/*.tokens.json` and `semantic/**/*.tokens.json` (see `sd.config.mjs` `source` globs)
- Colocated component tokens collected into SD input by `build.mjs`

### Build
- **Config**: `scripts/build/styledictionary/sd.config.mjs` — transforms, formats, platforms (SSOT for SD5 output paths)
- **Runner**: `scripts/build/styledictionary/build.mjs` — collectors + `buildAllPlatforms()` + barrel files
- **Command**: `pnpm ds:tokens:build`
- **Transforms**: DTCG flatteners + `colorOklch`, `dimensionToCss`, `shadowCssShorthand`, `gradientCssShorthand`, etc.
- **Preprocessor**: `coldlight/capture-extensions` — captures `$extensions.com.coldlight` before SD5 strips group-level extensions
- **Formats**: `coldlight/css`, `coldlight/tailwind-theme`, `coldlight/types`, `coldlight/manifest`
- **Platforms**: css-primitives, css-semantic, css-components, theme-*, types-*, manifest, css-svg-presets (see `sd.config.mjs`)

### Output
```
src/lib/design/styles/primitives/*.css   — @layer tokens.primitives
src/lib/design/styles/semantic/*.css     — @layer tokens.semantic
src/lib/design/styles/components/*.css   — @layer tokens.components (generated)
src/lib/design/theme/*.css               — Tailwind v4 @theme blocks per domain
src/lib/design/types/*.d.ts              — TypeScript const arrays + union types
src/lib/design/generated/token-manifest.json — VPB metadata
src/lib/design/svg/presets/svg-presets.generated.css — SVG preset vars
```
Non-token runtime CSS (`generated/*.css` for typography/focus/keyframes, `svg/*` glue) stays outside `styles/` and is imported from `src/lib/design/index.css`.

### Token Authoring Rules
- **Colors**: Author as HEX in JSON. SD5 transform → oklch for CSS output.
- **Dimensions**: Author as PX in JSON. SD5 transform → rem for CSS output.
- **Shadows**: DTCG shadow objects. SD5 built-in → CSS shorthand.
- **Gradients**: DTCG gradient type with HEX stops. Custom transform → linear-gradient().
- **Cubic Bezier**: Array `[x1, y1, x2, y2]`. SD5 built-in → cubic-bezier().
- **References**: `{group.path.leaf}` syntax for cross-token references.
- **Extensions**: `$extensions.com.coldlight` for VPB scale metadata.

## 8-Axis Encoding System

**SSOT**: `registry/token-categories.ts`

| Code | Category | Description | VPB Control |
|------|----------|-------------|-------------|
| `s` | Surface | Fill, backdrop-filter, opacity. Glass types include blur. | select |
| `z` | Material | Physics: glass clarity, matte, metal chrome/copper | select |
| `d` | Depth | Z-elevation via drop shadows (z0–z4) | slider |
| `b` | Bevel | Neumorphic inset shadows + SVG specular + noise | slider |
| `g` | Glow | Emission halo: accent color + intensity + spread | select |
| `f` | Frame | Border: none/soft/hard/glow/accent-teal/accent-purple | select |
| `m` | Motion | Ambient animations (breathe, shimmer, drift, pulse) | select |
| `t` | Transition | User-triggered speed + easing | select |

### Encoding Format
```
v-s3z1d2b1g0f1m0t2   (full explicit)
v-s3 v-d2 v-t2        (composable segments)
btn-primary v-g2       (semantic + override)
```

### FOCUS Context Modifiers (applied at resolve time)
```
low:      { b: -1, g: -1, d: -1, t: +1 }
medium:   {} (baseline)
high:     { b: +1, g: +1, d: +1, t: -1 }
critical: { b: +2, g: +2, d: +2, t: -2 }
```

## Component Library

### Structure (89 kinds)
```
components/{kind}/
├── {Kind}.svelte          — useColdLight() + cn(recipe(), visual.segments, visual.radius)
├── types.ts               — Props extending ColdLightProps, PRESET_MAP
├── contract.ts            — W3C ARIA spec (ComponentContract)
├── recipe.ts              — Structural layout only (Tailwind classes, no tokens)
├── index.ts               — Barrel exports
└── {Kind}.test.ts         — Vitest browser tests
```

### Component Resolution Flow
```
<Button intent="primary" glow="teal" depth="z2">
  → types.ts: PRESET_MAP[intent] → "btn-primary"
  → useColdLight({ preset, surface, depth, glow, ... })
  → resolveVisual(input) → ResolvedVisual
  → cn(recipe(size), visual.segments, visual.radius, className)
  → DOM: class="btn h-10 px-4 v-s1 v-d2 v-g1 rounded-lg" data-encoding="v-s1d2g1"
```

### Key Files
- `components/_base/use-coldlight.svelte.ts` — Svelte 5 rune wrapper
- `components/_base/schema.ts` — ComponentSchema (props, slots, tokenAxes, recipe binding)
- `components/_schema/contract.ts` — ComponentContract (W3C ARIA per slot)

## Recipe System

32 registered recipes. Each recipe = per-slot class strings for LAYOUT ONLY:

```typescript
registerRecipe({
  id: "button.default",
  kind: "button",
  slots: {
    root: { base: "inline-flex items-center justify-center", visual: "all" },
    icon: { base: "shrink-0", visual: "none" },
```

## SVG Neumorphism Engine

NOT CSS approximations. Real SVG filter primitives:

| Filter | SVG Primitives | What It Does |
|--------|---------------|-------------|
| **Bevel** | `feSpecularLighting`, `fePointLight` | Phong model 3D edge highlights |
| **Glow** | `feFlood`, `feGaussianBlur`, `feColorMatrix` | Shape-aware emission halos |
| **Noise** | `feTurbulence`, `feDisplacementMap` | Surface grain texture |

Location: `svg/filters/`
- `definitions/bevel.ts` — parameterized (surfaceScale, specularConstant, lightPosition)
- `definitions/glow.ts` — parameterized (shape, blur radius, color matrix)
- `definitions/noise.ts` — parameterized (frequency, scale)
- `SvgFilters.svelte` — renders all filter defs into DOM
- `filters.css` — @utility classes: `filter-bevel-soft`, `filter-glow-teal`, etc.
- `registry.ts` — filter lookup + manifest export for VPB

One SVG filter replaces 6-8 layered CSS hacks for neumorphism.

## VPB (Visual Page Builder)

No-code visual editor that reads:
- Token manifest → generates sliders/knobs for each token axis
- Preset registry → shows preset palette
- Recipe registry → shows recipe options
- Filter manifest → generates SVG filter parameter controls

Features:
- Directional gradient system (two-color blend, adjustable angle, feather radius)
- Material preset selection (glass, metal, matte)
- Parameter adjustment via sliders/knobs
- Real-time optimized neumorphic output preview
- Code generation (Svelte + props)

**Junior devs never write CSS. They compose via VPB.**
