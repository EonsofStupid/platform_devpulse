# ColdLight

**Token-driven neumorphic design system for DevPulse.**

ColdLight is a publishable package (`@devpulse/coldlight`) that owns all CSS, all components, and all UI generation. Inspired by React Spectrum S2 — components are sealed, customization happens at the token layer via presets.

---

## How It Works

```
Token JSON (DTCG)
  → Style Dictionary 5
    → CSS Custom Properties
      → Tailwind @theme
        → Recipes (structural classes)
          → Shards (semantic HTML + data attributes)
            → Hooks (ARIA + keyboard + state)
              → Components (what users import)
                → Presets (named 8-axis visual configs)
                  → Blocks (page compositions)
```

## 8-Axis Visual Encoding

Every visual in ColdLight is described by 8 axes:

| Axis | Code | Controls |
|------|------|----------|
| Surface | `s` | Fill, backdrop-filter, opacity |
| Material | `z` | Glass clarity, matte, metal |
| Depth | `d` | Drop shadow elevation (z0–z4) |
| Bevel | `b` | Neumorphic inset shadows + SVG specular |
| Glow | `g` | Emission halo — accent color + intensity |
| Frame | `f` | Border treatment |
| Motion | `m` | Ambient animation |
| Transition | `t` | User-triggered speed + easing |

Encoding format: `v-s3z0d2b2g1f1m0t1`
