## Problem

91 components have identical placeholder `@defaults` values. No central preset registry.
No typed strings. The VPB has nothing to enumerate. resolveMacro reads `string` for
kind and preset — anything goes, nothing validates.

## Phase 1: Central Type Registry

### 1.1 KindName — generated union from anatomy declarations

```typescript
// generated/kind-registry.ts (BUILD-TIME GENERATED)
export type KindName =
  | "accordion" | "alert-dialog" | "badge" | "button" | "checkbox"
  | ... // all 64 primitive kinds
  ;

export const KIND_NAMES: readonly KindName[] = [...] as const;
```

Generated by scanning `primitives/*/anatomy.ts` at build time.

### 1.2 PresetFamily — the visual families

```typescript
// visual/preset-families.ts
export type PresetFamily =
  | "neuro"      // neumorphic depth, inset shadows, carved surfaces
  | "glass"      // backdrop-blur, translucent, frosted
  | "retro"      // thick borders, stepped corners, pixel-art, CRT glow
  | "chrome"     // liquid metal, specular highlights, mercury
  | "flat"       // minimal, matte, no depth
  | "stark"      // high contrast, bold borders, dramatic shadows
  ;

export const PRESET_FAMILIES: readonly PresetFamily[] = [
  "neuro", "glass", "retro", "chrome", "flat", "stark",
] as const;
```

### 1.3 PresetId — the compound identifier

```typescript
// visual/preset-id.ts
export type PresetVariant = "elevated" | "deep" | "minimal" | "solid" | "glow" | "muted";

/** Full preset ID: "{family}-{variant}" */
export type PresetId = `${PresetFamily}-${PresetVariant}`;

/** Semantic intent → preset mapping */
export type SemanticIntent = "primary" | "secondary" | "ghost" | "danger" | "neutral";
```

### 1.4 SizeName — central sizing

```typescript
// visual/sizes.ts
export type SizeName = "xs" | "sm" | "md" | "lg" | "xl";
export const SIZE_NAMES: readonly SizeName[] = ["xs", "sm", "md", "lg", "xl"] as const;
```

### 1.5 MacroInput — typed, not bare strings

```typescript
export interface MacroInput {
  kind: KindName;
  preset?: PresetId | SemanticIntent;
  state?: MacroState;
}
```

## Phase 2: Central Preset Library

### Structure

```
visual/
  preset-families.ts      — PresetFamily type + PRESET_FAMILIES const
  preset-id.ts            — PresetId, PresetVariant, SemanticIntent
  sizes.ts                — SizeName, SIZE_NAMES
  intent-map.ts           — typed SemanticIntent → PresetId mapping
  presets/
    neuro.ts              — neuro-elevated, neuro-deep, neuro-minimal, ...
    glass.ts              — glass-elevated, glass-deep, glass-minimal, ...
    retro.ts              — retro-elevated, retro-deep, retro-solid, ...
    chrome.ts             — chrome-elevated, chrome-glow, ...
    flat.ts               — flat-minimal, flat-solid, flat-muted, ...
    stark.ts              — stark-elevated, stark-glow, stark-solid, ...
    index.ts              — barrel: PRESET_LIBRARY (all presets by ID)
```

### Preset Shape

Each preset is a typed object of 11-axis DTCG token references:

```typescript
export interface PresetDefinition {
  readonly id: PresetId;
  readonly family: PresetFamily;
  readonly variant: PresetVariant;
  readonly label: string;
  readonly axes: {
    readonly backgroundColor: string;    // DTCG color reference
    readonly backgroundBlur: string;     // dimension
    readonly shadow: string;             // shadow (multi-layer)
    readonly border: string;             // border composite
    readonly animation: string;          // duration
    readonly transition: string;         // transition composite
    readonly typography: string;         // typography composite
    readonly gradient: string;           // gradient
    readonly color: string;              // foreground color
    readonly borderRadius: string;       // dimension
    readonly opacity: string;            // number
  };
}
```

### Preset Authoring — Per Family Visual Checklist

#### NEURO family
- [ ] Surface feels CARVED into the page — inset shadows mandatory
- [ ] Dual-layer shadows: ambient (spread) + directional (offset)
- [ ] Highlight rim: `inset 0 1px 0 rgba(255,255,255,0.06)` minimum
- [ ] Background: dark, slightly lighter than page void
- [ ] No flat borders — border is part of the shadow stack

#### GLASS family
- [ ] Real backdrop-blur: 8-16px minimum (not 2px fake blur)
- [ ] Multi-layer opacity: surface + inner glow
- [ ] Frosted glass over dark backgrounds
- [ ] Border: rgba teal/white at 0.1-0.3 opacity
- [ ] Readable text contrast OVER the glass

#### RETRO family
- [ ] Thick borders: 2-4px minimum, solid or double
- [ ] Stepped/pixelated corners: border-radius 0 or 2px (never smooth)
- [ ] Bold saturated colors — not muted, not pastel
- [ ] CRT glow: text-shadow with color emission
- [ ] Pixel-grid feel: all dimensions in multiples of 4px
- [ ] Mono font option for that terminal aesthetic

#### CHROME family
- [ ] Specular highlights: gradient from bright to dark in < 8px
- [ ] Mercury reflection: conic or linear gradient on surface
- [ ] SVG filter integration: feSpecularLighting, feGaussianBlur
- [ ] Cool-toned: silver, steel, ice blue
- [ ] Motion: subtle shimmer on hover

#### FLAT family
- [ ] Zero shadows
- [ ] Zero borders OR 1px solid only
- [ ] Solid backgrounds — no transparency, no blur
- [ ] Clean, geometric
- [ ] Fastest rendering — no composite operations

#### STARK family
- [ ] Maximum contrast: dark bg + bright border OR bright bg + dark text
- [ ] Bold shadows: z2+ minimum
- [ ] Thick borders: 2px+ with high-contrast color
- [ ] Dramatic but not playful — executive, bold, commanding

## Phase 3: SD5 Token Compilation

Each preset becomes a token group in SD5:

```json
{
  "style": {
    "button": {
      "neuro-elevated": {
        "background-color": { "$type": "color", "$value": "oklch(0.15 0.01 240)" },
        "box-shadow": { "$type": "shadow", "$value": [
          { "offsetX": "0", "offsetY": "2px", "blur": "4px", "spread": "0", "color": "oklch(0 0 0 / 0.4)" },
          { "offsetX": "0", "offsetY": "-1px", "blur": "0", "spread": "0", "color": "oklch(1 0 0 / 0.06)", "inset": true }
        ]},
        ...
      },
      "retro-solid": {
        "background-color": { "$type": "color", "$value": "oklch(0.55 0.2 160)" },
        "border-width": { "$type": "dimension", "$value": "3px" },
        "border-radius": { "$type": "dimension", "$value": "2px" },
        ...
      }
    }
  }
}
```

SD5 compiles to: `--style-button-neuro-elevated-background-color: oklch(0.15 0.01 240);`

resolveMacro reads these at runtime via `var()` chains. Already built.

## Phase 4: VPB Integration

The VPB reads the typed registry at runtime:

1. `KIND_NAMES` → which components exist → component picker
2. `PRESET_FAMILIES` → which families exist → family tab selector
3. `PRESET_LIBRARY[presetId].axes` → which axes have values → sliders/knobs
4. Each axis → typed range (color picker, dimension slider, shadow editor, etc.)
5. User adjusts → live preview via `resolveMacro()` with overridden values
6. Save → new PresetDefinition → central library → SD5 recompile

### Image Layer (webp/png with alpha)

New token type for background-image with alpha control:

```typescript
// In PresetDefinition.axes:
readonly backgroundImage?: string;   // URL to webp/png asset
readonly backgroundAlpha?: string;   // number 0-1, controls mix-blend-mode opacity
```

The VPB provides:
- Image picker (upload webp/png)
- Alpha slider (controls the image layer opacity)
- Blend mode selector (normal, multiply, screen, overlay)
- This lets users layer translucent images UNDER the glass/neuro surface

## Phase 5: Component @defaults Cleanup

After presets are authored, the `@defaults` blocks in every component header
get replaced with a preset reference:

```html
<!--
  @defaultPreset neuro-elevated
  @presets neuro-elevated, neuro-deep, glass-deep, retro-solid, chrome-glow, flat-minimal, stark-elevated
-->
```

The scanner reads `@defaultPreset` and `@presets` to generate the catalog.
No more hardcoded oklch values in HTML comments.

## CHECKLIST — Per Preset

- [ ] All 11 axes have values (no empty strings)
- [ ] Values are DTCG references or resolved oklch/rem (no hex, no px)
- [ ] Shadow is multi-layer (at least 2 layers for neuro/chrome/stark)
- [ ] Border-radius matches family (0-2px for retro, smooth for glass/neuro)
- [ ] Background color contrasts with foreground color (WCAG AA minimum)
- [ ] Typography references use token aliases ({font.sans}, {font.mono})
- [ ] The preset is VISUALLY DISTINCT from other families at a glance
- [ ] Tested on button, card, badge, dialog (4 component shapes minimum)
