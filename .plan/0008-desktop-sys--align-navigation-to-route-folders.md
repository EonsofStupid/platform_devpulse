# Navigation comes from the route folders, generated at build

## Goal

`src/routes` is the only place a route exists. Every list of routes (the
sidebar, its submenus, the devtools dashboard, the runtimes page) is built at
build time from the route folders, every link is checked against SvelteKit's
generated route list, and the Rust window roles use route constants generated
from the same folders. Adding a page means adding a folder — nothing else.

any export with a `_` prefix (`@sveltejs/kit/src/utils/exports.js:13,19`).

## The pattern

- **Each route folder describes itself.** `+page.ts` exports `_nav` (icon,
  order, placement, status, accent, runtime id, capability). Folder-level
  facts (devtools tier and bucket: icon, accent, order) live in that folder's
  `+layout.ts` `_nav`. No route string anywhere.
- **The manifest is generated at build.** `lib/sys/routing/route-manifest.ts`
  uses `import.meta.glob` over `src/routes` (Vite turns it into a static map
  at build): the page set from `+page.svelte`, metadata from `_nav`. It builds
  the route tree with group names stripped. Tier and bucket come from the
  folder path `devtools/{tier}/{bucket}/{id}`.
- **Labels come from the copy catalog**, keyed by route path
  (`[nav."/devtools/system/datastores/turso"]`), merged with the user's
  `copy.toml` like every other key. A test fails when a page has no label or
  a label names a path that is not a route.
- **Point links** use `resolve()` from `$app/paths`, checked against the
  generated `Pathname` — a removed route fails the build.
- **Rust** gets route constants generated by `src-tauri/build.rs` from the
  same folders; a window role pointing at a missing route does not compile.
- **A gate** (`scripts/hooks/no-hand-typed-routes.mjs`) rejects new string
  routes in `href` / `goto` / `redirect` / `location` / route props.

## Non-goals

- No change to what any page renders, beyond labels moving to copy.
- No new routes except the MongoDB devtool folder, which the dashboard
  already shows as planned and which today links to nothing.
- Window behaviour (sizes, decorations) stays in Rust; only its routes change.
